# Android 客户端约束

- UI、布局、字体、色彩、图标与动效仅参考固定版本 FlClash/Prism UI；不复用 Web 资源或设计。
- Web 只提供 API 与业务数据语义。
- A0/A1 仅内存演示，明确标识，不连接生产、不引入认证或网络/持久化依赖。
- 使用 Flutter widgets 与 prism_ui，不使用 Material/Cupertino 外观替代已选定组件。
- 依赖保持固定引用；动效优先沿用 Prism 的组件和参数。

- A2 使用真实 API 的只读数据、origin 绑定的会话与快照；仅登录/退出允许 POST，不发送任务写入、校园同步或分类请求。

- A3 允许通过现有 API 新建/部分更新/删除任务。自动化 CRUD 与故障注入仅使用隔离本地服务；生产仅正常用户操作。草稿不得被刷新覆盖，未知写入不得自动重发。
- 用户已明确暂缓短暂掉帧优化，本阶段不调整渲染后端、玻璃或动效。

- A4 补齐日历、项目、象限分类、原生备注图片和设置；校园同步与 AI 分类只由显式操作触发，默认分类保留已有象限。自动化验证继续只用隔离本地服务，不改生产接口。
- 后台同步与手机消息提醒已由用户加入 A6，当前 A4 不提前增加调度或通知权限。

- A5/A6 已获授权：固定兼容现用证书的个人 Release 签名；通过 Android 系统任务约30分钟只读拉取，提醒新校园任务与到期任务。保持 FlClash 样式，不优化已暂缓的渲染路径。通知/故障验证使用隔离服务；生产仅正常读取与本人明确操作。
