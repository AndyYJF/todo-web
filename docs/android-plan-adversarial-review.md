# Android 计划对抗审查

2026-11-17；审查对象：8275df4 的开发计划。用户已授权修正后实施 A0/A1。

## 结论

发现并修正 3 项 P1、2 项 P2；未发现需要修改生产接口的 P0。审查聚焦既定计划与 API 合约，没有扩展到无关服务审计。

| 级别 | 问题及影响 | 本次修正 |
| --- | --- | --- |
| P1 | 计划未将 Web 视觉复用列为硬性排除，四象限描述容易导致照搬网页坐标布局 | UI/布局/字体/色彩/图标/动效仅沿用 FlClash；Web 仅提供业务数据和 API |
| P1 | 只合并刷新请求不能阻止旧 GET 响应覆盖稍后成功的写入 | A3 明确请求/写入代次与过期结果丢弃，编辑草稿独立 |
| P1 | 可配置服务器地址却缺少会话、缓存和 origin 切换规则 | 切换 origin 清理旧数据并重新登录；跨源跳转不携带 Cookie；退出不夸大会话吊销能力 |
| P2 | 初始依赖与交付范围混合了 A1 演示和 A2 网络，容易产生假同步状态或提前扩建 | A0/A1 仅 Prism 和内存演示，明确演示标识；Dio/持久化延至 A2 |
| P2 | UI 验收描述缺少具体的演示数据与交互路径 | 补充边界任务、截图/录屏、键盘/返回与减少动画场景 |

## 实施边界

A0/A1 使用 Flutter 与同版 Prism UI；独立 mobile 工程；不读取或写入生产任务，不调整 Next.js、认证、数据库或校园同步。SDK/Prism 的实际构建兼容性在 A0 验证，不将未经构建的推荐版本当成已通过验证。没有可删除的应用代码；不为本次任务移除历史 Web 功能。

## 实施中补充发现

P1：固定版 Prism 的 Dock、路由/面板与分段控件没有统一读取系统减少动画设置。App 层保留同版正常动效，在减少动画下使用同色与同形状的静态导航、零时长路由/面板，禁用自包裹的弹性反馈；不修改上游依赖或引入 Web 样式。已在 API 35 模拟器将系统动画设置为 0，验证导航、新建与主题操作；随后恢复设置。实际验证记录见 android-a0-a1-progress.md。
