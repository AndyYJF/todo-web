# Android A4 实施记录

日期：2026-11-17（Asia/Singapore）。版本：0.4.0+4。

## 已实现

- 月历支持换月、回到今天、按日查看及全部/待办/完成筛选；按 UTC+8 的起止日期覆盖范围显示，未设日期单独查看。
- 项目沿用现有字符串分组，包含未分组任务；支持项目搜索、数量及组内任务搜索/状态筛选。
- 任务详情可选择四象限或同时清空 urgent/important。AI 默认只处理未分类的未完成任务；覆盖全部未完成任务是独立确认操作，明确会覆盖手动选择。
- 分类结果区分 AI 与规则兜底。API 的 failed 字段表示规则处理条数，不作为未保存条数显示。
- 设置集中放置主题、origin、会话到期、App 读取时间、快照及校园同步结果；手动校园同步需显式操作，普通刷新仅 GET。
- 起止时间使用 Prism 原生表单面板中的月历与时间输入，选择后回填草稿，保存前不提交服务端。
- 原生 Markdown 展示标题、段落、列表、强调、代码、链接及图片；不使用 WebView，不执行 HTML。HTTP/HTTPS 链接交给外部浏览器。
- 校园备注中的“图片：URL”转换为原生图片节点；图片经本站 /api/img 鉴权代理获取，支持加载、错误、重试及缩放查看。Cookie 仅发往 Todo origin，不直接访问第三方图片地址。

UI、主题、Dock、路由和面板动效继续采用固定版 FlClash/Prism。未调整渲染后端、高刷新率策略或玻璃效果。

## 请求与结果处理

分类与校园同步复用 A3 的单笔提交锁、持久化待确认记录及读写代次。写入前的慢 GET 不得覆盖新结果；结果未知时不自动重发，刷新用于本人核对，待确认记录在重启后仍保留。已有草稿不因服务操作丢失。

校园同步响应为有效结构的 HTTP 502 时，按已确认失败显示上游错误并重新读取状态，解除提交锁；异常或无法解析的响应保留待确认。图片遇到 401 时使共享会话失效并返回登录。

新增固定依赖仅为 markdown 7.3.1、url_launcher 6.3.3。生产后端与 Web 均无代码改动，无新增权限、常驻服务或离线写入队列。
